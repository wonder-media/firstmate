# UX seat

Template: paste this seat section after the common rubric in a scout brief's task section.
This optional role applies when the plan changes a captain-facing surface; it was not exercised in the initial Council dogfood.

YOUR SEAT: UX, counted scout.
Rank findings within these sections:

1. **Information hierarchy:** whether the captain can identify the important state, decision, and next action at a glance.
2. **Interaction model:** task flow, selection, confirmation, feedback, and recovery from mistakes, grounded in concrete user scenarios.
3. **Layout and phone:** readability, density, responsive behavior, and long or empty content using the project's existing design system.
4. **Keyboard and accessibility:** navigation, focus, labels, and discoverability of essential actions.
5. **Empty and error states:** what the captain sees when data is absent, stale, loading, partial, or failed.
6. **Design doctrine and regressions:** fit with the supplied captain preferences and existing product surfaces, and any accepted change that makes a prior flow worse.

Cite plan phrases or existing UI/file evidence; do not invent new product scope or substitute a personal design preference for a captain rule.
